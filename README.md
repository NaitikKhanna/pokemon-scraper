# Python Web Scraper

## Overview
A Python scraper that extracts product names, prices, and product URLs from a Pokémon product website.

## Features
- Multi-page scraping
- Data cleaning
- Duplicate removal
- Error handling
- CSV/Excel export

## Technologies
- Python
- Requests
- BeautifulSoup
- pandas
- openpyxl

## Output
Explain what the generated CSV/Excel contains.

## How to run
pip install -r requirements.txt
python scraper.py
